Träwelling Map Explorer Feature Guide

Pop in a username, zoom through your check-ins, and share the coolest routes with your Friends.

🚀 Launch Map Explorer 🔑 Grab an API Token (only for private profiles)

Quick Start

Enter Username

Type any Träwelling username you can view. Hit 🚀 Load Travel Data and the trips start rolling in.

Optional: API Token

Paste your Traewelling API token if you want to see private check-ins you already have access to.

Fetch & Explore

Intuitive menues and controls guide you while you Explore and filter your data. Longer histories can take time because we respect Träwelling’s rate limits.

Feature Highlights

Transport Layers

Route Density & Animation

Heatmaps highlight frequently travelled corridors.

Date Window

Use the from/to pickers to focus on a semester, a challenge month, or the latest vacation without re-fetching.

Account Switcher

Hop between friends or alt accounts from a tidy list. Everything stays on your device.

Stats & Moments

See total trips, total distance, and the oldest/newest check-ins at a glance—perfect for reminiscing.

Railway Basemap Overlay

Load high-resolution railway lines for spatial reference when exploring trips.

Hide Inaccurate Toggle

Filter out likely inacurate check-ins with a single switch so your map stays clean and story-ready.

Delay Tracker

A fresh Delay mode now highlights your most impacted services and trips and helps you remember your worst trips more easily.

Saved Sessions

Recent usernames and trips stay cached locally for faster reloads (up to 30 days) or can be cleared manually.

Touch-Friendly Menus

Large tap targets, swipeable lists, and haptic-safe toggles keep everything comfy on smaller screens.

Data & Privacy Notes

Where data lives

No data is uploaded anywhere else.

  • Trips are fetched directly from https://traewelling.de/api/v1 when you ask for them.
  • Your browser keeps the temporary bits it needs locally—no cloud sync, no surprise uploads.

Good housekeeping

  • Keep API tokens secret. Never paste them into shared screens or streams.
  • Private profiles stay private. You’ll only see them if you supply the API token tied to an account that already has access through Träwelling.
  • Use the 🧹 “Clear cached data” action whenever you want a clean slate.

FAQ

Do I need an API token?

No. Public profiles work without it. Tokens are only required for private profiles or private check-ins.

Can I export the trips?

Map Explorer focuses on visual exploration. For CSV exports, use Träwelling’s native export or the official API directly. Advanced users can poke around their browser’s IndexedDB to grab cached data, but that path isn’t documented or supported.

Does caching sync between browsers?

Caching is local-only for privacy reasons. Use the same browser profile if you want persistent sessions.

Is there a mobile mode?

Yes. The UI switches to a compact menu, gestures are touch-friendly, and stats can be accessed through the floating “📊” toggle.
