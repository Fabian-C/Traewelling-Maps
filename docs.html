👥 Filtering Check-ins by Number of Travel Buddies

Every journey record tracks companions from official bodyMentions, buddies, and inline @username check-in tags. You can filter trips by the exact or minimum number of companions using the numeric buddy_count column.

👥 Group Travel: 2 or More Travel Buddies

Finds all check-ins shared with two or more companions, sorted by the largest travel party first.

SELECT line, origin, destination, buddies, buddy_count, departure
FROM trips
WHERE buddy_count >= 2
ORDER BY buddy_count DESC;
🤝 Joint Journeys: At Least 1 Companion

Returns all check-ins where you travelled with at least one companion (equivalent to WHERE buddies IS NOT NULL).

SELECT line, origin, destination, buddies, departure
FROM trips
WHERE buddy_count >= 1
ORDER BY departure DESC;
🚶 Solo Rides: No Travel Buddies (Zero Count)

Isolates solo travels where no fellow passengers or buddies were tagged.

SELECT line, origin, destination, distance_km, departure
FROM trips
WHERE buddy_count = 0
ORDER BY departure DESC;
👫 Duo Rides: Exactly 1 Travel Companion

Isolates journeys where you travelled with exactly one specific travel partner.

SELECT line, origin, destination, buddies, departure
FROM trips
WHERE buddy_count = 1
ORDER BY departure DESC;
🚄 High-Speed Group Rides (ICE / TGV with 2+ Buddies)

Combines transport category filtering with companion counts to identify long-distance group excursions.

SELECT line, origin, destination, distance_km, buddies, buddy_count
FROM trips
WHERE category = 'nationalExpress' AND buddy_count >= 2
ORDER BY distance_km DESC;
🔍 Journeys with a Specific Travel Partner

Performs a pattern match across companions to isolate joint trips with a particular username (replace Fabi with your buddy's username).

SELECT line, origin, destination, buddies, departure
FROM trips
WHERE buddies LIKE '%Fabi%'
ORDER BY departure DESC;

🎛️ How to Filter by Buddy Count in the Visual Query Builder (No SQL Required)

If you prefer not to write raw SQL, you can use the interactive Visual Query Builder inside the Studio tab:

  1. Open trips.html and click ⚡ Database Studio.
  2. Ensure the 🧩 Visual Query Builder tab is active.
  3. Click ➕ Add Condition.
  4. In the column dropdown, select Buddy Count (buddy_count).
  5. In the operator dropdown, choose >= greater than or equal (or = equals).
  6. In the number input, type your desired number of companions (e.g. 2).
  7. Click ▶ Run Query. The SQL will be generated and evaluated instantly, displaying matching trips with rich expandable rows.

Data & Privacy Architecture

Zero Cloud Intermediaries

Local-First Execution

  • Direct API Calls: All data requests travel directly between your browser and https://traewelling.de/api/v1.
  • No Backend Server: Träwelling Map Explorer runs 100% on static client-side JavaScript. No analytics, tracking, or proxy servers exist.
  • PKCE Security: OAuth tokens are exchanged directly in the browser using PKCE without exposing client secrets.

Local Storage Management

  • Encrypted IndexedDB: Cached trips and tokens remain in your browser's private origin storage.
  • Clear Cache: Tap 🧹 Clear Cached Data at any time to purge all stored accounts, tokens, and check-in records.
  • Token Safety: Personal Access Tokens are stored only if you choose "Remember Token" and never leave your machine.

Frequently Asked Questions

How can I filter check-ins by the number of travel buddies?

Go to Trip Database and open Database Studio. In the SQL Console, run SELECT * FROM trips WHERE buddy_count >= 2 to view group trips, or SELECT * FROM trips WHERE buddy_count = 0 for solo rides. Alternatively, add a condition in the Visual Query Builder choosing Buddy Count with operator >= or =.

How does 1-Click Login work?

It uses standard OAuth 2.0 Authorization Code Flow with PKCE. Clicking Log in with Träwelling opens Träwelling’s official authorization screen where you grant read-only permissions for check-ins and statistics. Träwelling redirects back with an authorization code that your browser exchanges directly for an access token.

Can I explore someone else’s map while logged in?

Yes! Once authenticated, your username is selected by default, but you can enter any public Träwelling username into the "User to explore" input to map their public journeys.

How does Travel Buddy filtering work on the map?

Träwelling records companion data in official bodyMentions and createdBy API fields. The app tallies all journeys taken together and displays them in the 👥 Travel Buddies menu. Clicking a companion filters the map routes, heatmap, and trip statistics to only your journeys with that buddy.

Can I export my trips to GIS or Google Earth?

Yes! Click 📤 Export GeoJSON in the Statistics panel or menu to download your active routes as standard GeoJSON or copy the GeoJSON string directly to your clipboard. In Database Studio, you can also export queried datasets as CSV or JSON.

Does caching sync between different devices?

No. For privacy, caching is restricted to your current browser's local IndexedDB. If you switch devices or browsers, simply log in again or re-enter the username to fetch your data.
