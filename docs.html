Documentation & User Manual

Träwelling Maps & Database Studio

A high-performance, privacy-first web platform for visualizing, querying, filtering, and exporting your entire Träwelling transit and rail travel history.

🚀 Launch Database Studio 🗺️ Open Interactive Map ⚡ SQL Recipes

🚀 Overview & Architecture

Träwelling Maps transforms your personal train, transit, and ferry check-ins into an interactive spatial network and relational database. Built without heavy frontend frameworks or remote database dependencies, everything runs 100% client-side in your browser.

🗺️

Interactive Route Map

Visualizes real transit geometries, station markers, punctuality tiers, platform changes, and custom check-in notes.

⚡

In-Memory SQL Studio

Executes arbitrary SQL queries with filtering, sorting, aggregations, companion criteria, and pagination in sub-millisecond execution times.

👥

Travel Companion Tracking

Native relational tracking for friends traveling together via buddies and buddy_count predicates.

✨

Annual Rail Wrapped

Calculates year-end transit analytics, carbon savings, top train lines, and pure rail longest journeys (excluding flights).

💡
Architecture Highlight
All parsing, caching (via IndexedDB), filtering, and SQL evaluation happens directly in your browser. No travel history or credentials ever leave your device.

⚡ Quick Start Setup

You can start exploring immediately using either an OAuth2 account connection or by loading any public Träwelling username.

Option A: Connect via OAuth2

Click Connect with Träwelling on the main map. Authenticate securely via Träwelling's official OAuth2 provider to automatically sync all your private and public check-ins with full comments, platform info, and tickets.

Option B: Inspect Any Public Profile

Enter any Träwelling username in the search input (e.g., https://traewelling.de/profile/username). The app fetches public statuses via Träwelling's public API and caches them in your local browser storage.

🔑 OAuth2 vs Public Profiles

Träwelling provides two ways to access your journey data. Below is a breakdown of capabilities available in each mode:

🛡️ 100% Client-Side Privacy

We believe your transit history is personal. Träwelling Maps is designed with a strict zero-telemetry, zero-remote-database philosophy:

  • No Backend Server: The application is statically hosted. There is no remote backend server collecting, logging, or storing your data.
  • Direct API Communication: All network requests communicate directly between your browser and traewelling.de via HTTPS.
  • Local IndexedDB Storage: Credentials and cached journeys are stored strictly in your browser's local sandbox (SessionDB).
  • Easy Cache Eviction: You can clear your cached sessions at any time with a single click.

🗺️ Interactive Route Map

The interactive map transforms individual check-in statuses into contiguous geographic polylines across regional, national, and international transit networks.

Category Color Schemes

ICE and high-speed rail glow red, regional express lines appear in cyan, S-Bahn lines shine emerald, and ferries are marked in teal.

Time Scrubbing Slider

Filter your journeys across specific years, months, or date ranges with real-time route rendering.

Punctuality Badges

Each journey displays departure and arrival punctuality tiers, from punctual (≤5 min) to severe delays (>30 min).

🔗 Direct Deep-Linking

You can link directly to any specific journey across both the Map Explorer and Database Studio using URL parameters:

Deep Link URL Pattern
index.html?user=resu&trip=325374
💡
Automatic Map Pan & Detail Zoom
Opening an index.html?user=...&trip=... deep-link automatically centers the map onto the journey's polyline coordinates and opens the rich station popup.

🗂️ Trip Database Explorer

The Trip Database (trips.html) provides an advanced search engine and relational workbench for your journeys.

Live Text Search

Instantly searches line names, train numbers, origin/destination stations, check-in comments, and buddy mentions (e.g., @Fabi).

Multi-Select Categories

Filter multiple transport modes simultaneously (e.g. High-Speed + Regional + Ferry).

Telemetry Analytics Bar

Live telemetry showing matched journeys, total distance (with Earth lap comparison), punctuality rate, interactive travel time (hours/days/months), and avoided carbon emissions vs passenger cars.

📊 Unified Table vs. Raw SQL Grid

Database Studio includes two complementary table display modes accessible via the [ 📋 Unified | 📊 Raw SQL ] format switcher in the results bar:

📋 Unified Explorer Mode (Default)

Rich visual cards with transport mode icons, punctuality pills, interactive travel companion chips with profile links, and an expandable check-in drawer showing scheduled vs actual times, platforms, and check-in notes.

📊 Raw SQL Output Mode

Designed for SQL users: renders the exact projected relational table matching your SELECT clause. Displays typed column headers (TEXT, NUM, DATE), right-aligned monospace numbers, row indices (#), and explicit NULL badges.

⚡ In-Memory SQL Studio

Database Studio features a full SQL tokenizer, recursive-descent query parser, and evaluation engine executing in Web Workers or main thread. It evaluates complex logical expressions with parenthesized groups against thousands of trips in under 1 millisecond.

⚡
Pure Relational SQL
Queries run against the virtual trips table. You can use standard SQL clauses: SELECT, WHERE, ORDER BY, LIMIT, and OFFSET.

👥 Travel Buddies & Group Travel Queries

Träwelling lets you check in alongside friends. In Database Studio, you can filter group trips using both text matching and numeric buddy counts:

Option 1: Using the buddy_count Numeric Column (Recommended)

The buddy_count column represents the exact count of travel buddies. This enables precise relational filtering:

Group Travel: Trips with at least 1 companion
🚀 Run in Studio 
SELECT line, origin, destination, buddies, buddy_count
FROM trips
WHERE buddy_count >= 1
ORDER BY buddy_count DESC;
Solo Journeys: Trips with no companions
🚀 Run in Studio 
SELECT line, origin, destination, distance_km, departure
FROM trips
WHERE buddy_count = 0
ORDER BY departure DESC;

Option 2: Without the buddy_count Parameter

If you prefer writing SQL against the raw string column buddies, you can use IS NOT NULL or pattern matching:

Find Trips with Buddies using IS NOT NULL or LIKE
🚀 Run in Studio 
-- Matches any trip where companions are attached
SELECT line, origin, destination, buddies, departure
FROM trips
WHERE buddies IS NOT NULL
ORDER BY departure DESC;

-- Or search for a specific friend's username
SELECT line, origin, destination, departure
FROM trips
WHERE buddies LIKE '%@Fabi%';

⚡ Pre-Built SQL Recipes

Try these curated SQL recipes directly in Database Studio or copy them with one click:

Top 10 Most Delayed Trips
🚀 Run in Studio 
SELECT line, origin, destination, delay_dep, departure
FROM trips
WHERE delay_dep > 15
ORDER BY delay_dep DESC
LIMIT 10;
High-Speed Long Distance Journeys (> 300 km)
🚀 Run in Studio 
SELECT line, origin, destination, distance_km, duration_min
FROM trips
WHERE category = 'nationalExpress' AND distance_km > 300
ORDER BY distance_km DESC;
Late Night & Early Morning Night Rides
🚀 Run in Studio 
SELECT line, origin, destination, departure, distance_km
FROM trips
WHERE (
    departure LIKE '%T22:%' OR departure LIKE '%T23:%' OR
    departure LIKE '%T00:%' OR departure LIKE '%T01:%' OR
    departure LIKE '%T02:%' OR departure LIKE '%T03:%'
)
ORDER BY departure DESC;
100% Punctual Regional Runs (Zero Delay)
🚀 Run in Studio 
SELECT line, origin, destination, distance_km, departure
FROM trips
WHERE category = 'regional' AND delay_dep = 0
ORDER BY departure DESC
LIMIT 20;

✨ Rail Wrapped Analytics

Rail Wrapped provides your annual Year in Review for railway and public transit journeys, complete with leaderboards and shareable social cards.

Carbon Avoidance Calculation

Estimates kilograms and tonnes of CO₂ emissions avoided compared to driving an average passenger vehicle (142g CO₂/km).

Station & Line Leaderboards

Calculates your most visited transfer hubs, favorite train lines, and punctuality grade.

🚂 Longest Journey (Flights Excluded)

To ensure Wrapped reflects genuine train and transit achievements, flights (planes) are strictly excluded from the "Longest Journey" milestone.

ℹ️
Rail-First Metric
Check-ins categorized as plane, flight, or airplane are excluded from the longest single journey calculation, ensuring the spotlight stays on high-speed rail, sleeper trains, and regional odysseys.

❓ Frequently Asked Questions

How do I refresh my journeys?

Click your user profile dropdown in the top header and re-select your profile or use the refresh action to sync newly logged check-ins.

Does the SQL engine support JOINs?

Currently, queries operate against the unified trips table which already flattens train status, platform, delay, companion, and check-in details into 17 columns.

Can I export query results to QGIS or Google Earth?

Yes! Click the 🗺️ GeoJSON export button in Database Studio to generate standard GeoJSON files compatible with QGIS, Mapbox, or Felt.
