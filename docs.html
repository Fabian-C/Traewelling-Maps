Data & Privacy Architecture

Zero Cloud Intermediaries

Local-First Execution

  • Direct API Calls: All data requests travel directly between your browser and https://traewelling.de/api/v1.
  • No Backend Server: Träwelling Map Explorer runs 100% on static client-side JavaScript. No analytics, tracking, or proxy servers exist.
  • PKCE Security: OAuth tokens are exchanged directly in the browser using PKCE without exposing client secrets.

Local Storage Management

  • Encrypted IndexedDB: Cached trips and tokens remain in your browser's private origin storage.
  • Clear Cache: Tap 🧹 Clear Cached Data at any time to purge all stored accounts, tokens, and check-in records.
  • Token Safety: Personal Access Tokens are stored only if you choose "Remember Token" and never leave your machine.

Frequently Asked Questions

How does 1-Click Login work?

It uses standard OAuth 2.0 Authorization Code Flow with PKCE. Clicking Log in with Träwelling opens Träwelling’s official authorization screen where you grant read-only permissions for check-ins and statistics. Träwelling redirects back with an authorization code that your browser exchanges directly for an access token.

Can I explore someone else’s map while logged in?

Yes! Once authenticated, your username is selected by default, but you can enter any public Träwelling username into the "User to explore" input to map their public journeys.

How does Travel Buddy filtering work?

Träwelling records companion data in official bodyMentions and createdBy API fields. The app tallies all journeys taken together and displays them in the 👥 Travel Buddies menu. Clicking a companion filters the map routes, heatmap, and trip statistics to only your journeys with that buddy.

Can I export my trips to GIS or Google Earth?

Yes! Click 📤 Export GeoJSON in the Statistics panel or menu to download your active routes as standard GeoJSON or copy the GeoJSON string directly to your clipboard. You can import this into QGIS, uMap, Google Earth, or GeoJSON.io.

Does caching sync between different devices?

No. For privacy, caching is restricted to your current browser's local IndexedDB. If you switch devices or browsers, simply log in again or re-enter the username to fetch your data.
