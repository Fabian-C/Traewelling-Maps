🗺️ The Interactive Route Map Explorer

The heart of the project: visualizing your train, transit, and ferry journeys on interactive railway networks.

Träwelling Maps is designed first and foremost to make your travel memories tangible. Rather than browsing raw lists of check-ins, the Map Explorer plots your actual train paths across countries, highlighting high-speed corridors, intermediate station stopovers, and ferry connections.

🛤️

Railway Network & Polylines

Every train journey is plotted using real-world railway tracks and station coordinates with vibrant color-coding by transit mode.

🚉

Intermediate Stations & Stopovers

Click on any journey to reveal the intermediate stops along the line, with scheduled timetables and actual arrival timestamps.

🔥

Track HeatMap Density

Toggle the HeatMap layer to visualize which corridors and tracks you ride the most, with customizable intensity and wave animations.

⚠️

Delay & Punctuality Highlights

Track delay metrics visually. Trips with significant delays glow in orange/red, with detailed delay causes and actual vs. scheduled times.

📸

Media & Check-in Notes

Interactive station popups display your check-in comments, travel buddy tags, and embedded photos or videos directly on the map.

🚦

Multi-Modal Transit Layers

Filter by transport category: High-Speed Rail (ICE/TGV/Eurostar), Regional, S-Bahn/Suburban, Subways, Trams, Buses, and Ferries.

💡

Direct Trip Sharing: You can link directly to any specific journey popup on the map by appending ?user=USERNAME&trip=STATUS_ID to the map URL.

Shareable Map URL Example 
index.html?user=USERNAME&trip=STATUS_ID

Trip Database & In-Memory SQL Studio

Powerful relational filtering and local query studio built into the browser.

While the Map Explorer lets you see journeys spatially, the Trip Database (trips.html) provides an advanced search engine and client-side SQL workbench. Every journey is loaded into an in-memory relational table (trips), enabling instant SQL queries without any backend database.

Interactive Pre-Built SQL Recipes

Run these popular queries directly in Database Studio or copy them with one click:

👥 Group Journeys with Travel Buddies
🚀 Run in Studio 
SELECT line, origin, destination, buddies, buddy_count
FROM trips
WHERE buddy_count >= 1
ORDER BY buddy_count DESC;
🚶 Solo Adventures (No Companions)
🚀 Run in Studio 
SELECT line, origin, destination, distance_km, departure
FROM trips
WHERE buddy_count = 0
ORDER BY departure DESC;
🚄 Long-Distance High-Speed Trips (> 300 km)
🚀 Run in Studio 
SELECT line, origin, destination, distance_km, duration_min
FROM trips
WHERE category = 'nationalExpress' AND distance_km > 300
ORDER BY distance_km DESC;
⚠️ Top 10 Heaviest Departure Delays (> 15 min)
🚀 Run in Studio 
SELECT line, origin, destination, delay_dep, departure
FROM trips
WHERE delay_dep > 15
ORDER BY delay_dep DESC
LIMIT 10;

📊 Relational Trips Table Schema

Complete reference of all 17 columns available in the in-memory database.

Table: trips
Column Type Description Sample Value
id NUM Unique check-in status ID on Träwelling 325374
line TEXT Train, transit line, or ferry identifier 'ICE 772', 'Fäh 62'
category TEXT Transport category (highspeed, regional, suburban, subway, tram, bus, ferry) 'nationalExpress', 'regional'
origin TEXT Departure origin station name 'Hamburg Hbf'
destination TEXT Arrival destination station name 'Berlin Hbf'
departure DATE Scheduled departure ISO timestamp '2024-05-12T08:30:00Z'
arrival DATE Scheduled arrival ISO timestamp '2024-05-12T10:15:00Z'
year NUM Year of departure 2024
delay_dep NUM Departure delay in minutes 12 (or 0 if punctual)
delay_arr NUM Arrival delay in minutes 25
distance_km NUM Traveled distance in kilometers 280.5
duration_min NUM Trip duration in minutes 105
operator TEXT Transit operator or railway provider 'DB Fernverkehr AG'
business TEXT Travel purpose category (private, business, commute) 'private', 'commute'
buddies TEXT Comma-separated travel buddies / buddy handles (@usernames) '@Fabi, @Alex'
buddy_count NUM Number of fellow travel companions on the journey 2 (or 0 for solo)
notes TEXT User check-in note, comment, or message body 'Ferry cruise on the Elbe'

📦 Data Exports & GeoJSON

Your data belongs to you: export routes for GIS, Google Earth, or archival backups.

Träwelling Maps supports full GeoJSON export directly from the map menu:

  • GeoJSON FeatureCollection: Export all or filtered routes as standardized GeoJSON linestrings and point markers, fully compatible with QGIS, ArcGIS, Mapbox, and Google Earth.
  • Intermediate Stopovers Option: Fetch and embed intermediate stations along routes before exporting for high-fidelity path reconstruction.
  • Offline Archival: Download raw JSON datasets or re-upload previously saved GeoJSON files directly into the map.

🔒 Privacy Architecture & FAQ

100% client-side execution with zero intermediary servers.

🛡️

Zero Cloud Intermediaries

Your authentication tokens, check-ins, and personal coordinates travel directly between your browser and the official Träwelling API. No middleman servers.

💾

Local Storage Control

All data is cached in your browser's IndexedDB. You can clear cached accounts and journey data with one click in the settings menu.

Frequently Asked Questions

Why are some train paths straight lines?

If intermediate route geometry is unavailable from the schedule provider for a legacy or rare train, the map draws a direct polyline between origin and destination.

Does this support foreign / international trains?

Yes! Any journey logged on Träwelling across DB, ÖBB, SBB, SNCF, Eurostar, Trenitalia, or ferries appears on the map seamlessly.
